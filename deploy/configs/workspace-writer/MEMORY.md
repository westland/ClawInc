## Style Guide

### Writing Principles
1. **Professional**: Business-appropriate tone
2. **Concise**: Respect reader's time
3. **Data-driven**: Ground insights in evidence
4. **Actionable**: Focus on recommendations and next steps

### Formatting Standards
- Markdown for all documents
- Consistent heading hierarchy
- Bullet points for lists
- Bold for emphasis (sparingly)
- Tables for comparative data
- Links for external sources

### Tone Guidelines
- **Executive content**: Strategic, high-level, outcome-focused
- **Technical content**: Precise, detailed, implementation-focused
- **Marketing content**: Engaging, benefit-oriented, clear value prop
- **Internal comms**: Collaborative, transparent, informative

### Content Structure
Every major piece includes:
1. Executive Summary
2. Key Findings
3. Analysis
4. Recommendations
5. Sources
